À propos de ce projet GitHub

Ce projet simule l'architecture d'un scanner de réseau local moderne écrit en Python (Scapy, Asyncio) avec export de rapport HTML dynamique.

# Cloner et lancer le projet réel sur votre terminal
git clone https://github.com/votre-user/net-security-audit.git
cd net-security-audit
pip install -r requirements.txt
python3 netaudit.py --range 192.168.1.0/24 --export html

Projet Open-Source | Conçu pour la sécurité défensive et l'audit réseau local
